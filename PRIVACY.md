# Privacy and cost

This native Qwen extension configures only the Suno tools backed by Ace Data Cloud. The package does not collect telemetry or send your workspace automatically. Qwen may send tool inputs chosen by you and the API Token to `https://suno.mcp.acedata.cloud/mcp`; the hosted implementation performs the corresponding Ace API operations. Do not submit content you lack permission to process.

The Token is entered through Qwen's sensitive extension setting. Qwen owns keychain/encrypted-file storage and its security settings; this source never includes a real credential. Keep Qwen and the operating system updated, avoid sharing credential files, and revoke the dedicated key from Ace Applications when no longer needed. Do not assume local disk encryption alone protects an unlocked account.

Media generation/editing can be billed under the selected application's current permissions, balance and prices. Connection, schema discovery or an installed package does not prove business success. This candidate makes no additional data-retention promise beyond the current Ace service terms and account controls. Review https://platform.acedata.cloud before use; contact dev@acedata.cloud with a task/trace ID, never your Token.
